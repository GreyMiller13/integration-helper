# О справочнике

Integration Helper — рабочий справочник системного аналитика по интеграциям между системами. Здесь собрано то, что постоянно нужно при проектировании и описании интеграций: от выбора протокола до кодов ответа, заголовков и требований к надёжности.

## Как устроен справочник

| Раздел | Что внутри | Когда открывать |
|---|---|---|
| [Протоколы и технологии](/protocols/) | REST, SOAP, GraphQL, gRPC, WebSocket, SSE, Webhooks, брокеры, файлы, форматы данных | Выбор способа интеграции, разговор со смежной командой |
| [HTTP](/http/basics) | Методы, коды состояния, заголовки, медиатипы | Описание конкретных методов API |
| [Проектирование REST API](/design/) | URI, идемпотентность, пагинация, фильтрация, кэш, ошибки, версии, лимиты | Проектирование контракта |
| [Безопасность](/security/) | Аутентификация, OAuth 2.0, JWT, TLS, CORS, OWASP | Требования к защите интеграции |
| [Надёжность и паттерны](/reliability/timeouts-retries) | Таймауты, повторы, circuit breaker, outbox, saga, мониторинг | Нефункциональные требования |
| [Спецификации](/specs/openapi) | OpenAPI, AsyncAPI, шаблон описания интеграции | Оформление постановки |
| [Инструменты](/tools/) | Postman, Bruno, curl, моки, тестирование | Проверка и отладка API |

## С чего начать

- Новая интеграция — пройдите по [чек-листу интеграции](/guide/integration-checklist) и заполните [шаблон описания](/specs/integration-template).
- Нужно выбрать технологию — [сравнение и дерево выбора](/protocols/).
- Быстро вспомнить код ответа — [коды состояния](/http/status-codes).
- Незнакомый термин — [глоссарий](/guide/glossary).

::: tip Поиск
Нажмите <kbd>Ctrl</kbd> + <kbd>K</kbd> (или <kbd>/</kbd>), чтобы искать по всему справочнику.
:::

## Как дополнять

Справочник хранится в git-репозитории, каждая страница — Markdown-файл в папке `docs/`. Правила оформления, поддерживаемый синтаксис (выноски, вкладки, диаграммы Mermaid) и подводные камни описаны в файле `CONTRIBUTING.md` в корне репозитория.

```bash
npm install      # один раз после клонирования
npm run dev      # локальный сервер с автообновлением: http://localhost:5173
npm run build    # проверка сборки и битых ссылок перед коммитом
```
